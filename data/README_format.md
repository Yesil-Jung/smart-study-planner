#  데이터 형식

모듈끼리 주고받는 데이터는 아래 형식을 따릅니다.

## 1. 시간표 (A: 예실, B:수안, C: 윤지, D: 서연 사용)
```json
{
  "owner": "윤지",
  "classes": [
    {"course": "자료구조", "day": "월", "start": "09:00", "end": "10:30"},
    {"course": "통계학", "day": "수", "start": "13:00", "end": "14:30"}
  ]
}
```
- 여러 명의 시간표는 리스트로 묶어서 사용: `[시간표1, 시간표2, ...]`

## 2. 일정 (A:예실 생성 → B:수안, D:서연 사용)
```json
{"course": "자료구조", "title": "과제2", "type": "과제", "due": "2026-12-05", "hours": 3}
```

## 3. 작업 블록 (B:수안 생성 → 화면 표시)
```json
{"title": "과제2", "date": "2026-12-02", "start": "13:00", "end": "15:00"}
```

## ✍️ 규칙
| 항목 | 형식 | 예시 |
|---|---|---|
| 요일 | `"월"` ~ `"일"` | `"수"` |
| 날짜 | `"YYYY-MM-DD"` | `"2026-12-05"` |
| 시간 | `"HH:MM"` (24시간제, 30분 단위) | `"13:30"` |
| type | `"과제"` / `"시험"` / `"퀴즈"` | `"시험"` |
| hours | 예상 소요시간 (숫자) | `3` |
